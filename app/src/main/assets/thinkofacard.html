Think Of A Card

There are 6 inputs required to get the card created on the phone:

  • The first input determines the color
  • The second will determine the suit on the said color
  • The remaining 4 inputs will tell which card is selected

Controls:

  • Up is equal to 1, Down is equal to 0
  • The color is 1 is Red, while 0 is Black
  • Depending on the color the suit table is as follows:
    • 1: Heart or Spade
    • 0: Diamond or Clubs

The values can be set as follows:

  • 0001, 1111: A
  • 0010: 2
  • 0011: 3
  • 0100: 4
  • 0101: 5
  • 0110: 6
  • 0111: 7
  • 1000: 8
  • 1001: 9
  • 1010: 10
  • 1011: J
  • 1100: Q
  • 1101: K

You can set the card using either headset sound buttons or the phone's sound button.
