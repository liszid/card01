Coin Through Phone

You can pull the coin in any direction. If the coin disappears from the screen, you can pull it back from any side. The default coin is a Morgan Dollar coin, with the size set.

There are two available configurations right now in the Settings menu for this module.

Coin Face: Determines whether you will be displaying Morgan coin or Eisenhower coin.

Coin Size: Size can be either Dollar size or Half-dollar size.

To be added later:

  • Face Up or Down: For pre-configured coins it is available to choose whether it will be shown face up or down.
  • Further Coin faces and sizes will be available later
  • Manually added coin face and size will be available later
